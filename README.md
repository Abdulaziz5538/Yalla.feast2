# Yalla Feast — Pure HTML, CSS & Vanilla JavaScript Website

A complete, responsive fast-food restaurant website built purely with **HTML5**, **CSS3**, and **Vanilla JavaScript** (no build step required — open `index.html` directly in any browser).

## Structure
- `index.html` — Full website structure (Navbar, Hero, Popular Cravings, Promo Banner, Interactive Menu, Combos, Why Choose Us, Customer Reviews, Branches, Contact, Newsletter, Footer, Modals & Drawers)
- `css/style.css` — CSS variables, Flexbox & Grid layouts, animations, responsive media queries
- `js/app.js` — 27 menu items across 9 categories, live search & sorting, customization modal, favorites, UZS cart with promo codes (`YALLA20`, `WELCOME15`), checkout & WhatsApp ordering
